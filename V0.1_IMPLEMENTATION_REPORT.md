## 7. Known Limitations & Deliberate Scope Boundaries

To maintain theological rigor and zero false claims, the following capabilities are explicitly feature-flagged OFF or mocked in V0.1:

1. **AI Religious Answering (`ISLAMIC_AI_ENABLED=false`):**
   - The AI Runtime and LLM prompt orchestrator are not connected to autonomous answering endpoints.
   - All religious answers in V0.1 are deterministic canonical lookups.
2. **Unverified Retrieval:**
   - Web crawling and arbitrary third-party Islamic API querying are strictly disabled. Only canonical Medina Mushaf and Kutub as-Sittah passages with verified provenance are queried.
3. **Autonomous Fatwas:**
   - The system is architecturally incapable of issuing fatwas. Sensitive queries (Class D/E) are immediately routed to human scholar queues or emergency care resources.
4. **Third-Party Telephony / CPaaS:**
   - The QSURA communication adapter operates with an in-memory/mock provider in local test environments; live SMS/WhatsApp traffic requires verified API credentials in production secrets.
5. **Live Stripe / Apple Pay Billing:**
   - Billing mechanisms utilize deterministic double-entry mock ledger fixtures; live payment provider webhooks remain disabled until public launch.
