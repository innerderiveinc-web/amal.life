# AMAL OS — Privacy Architecture & Data Sovereignty

## 1. Core Principle: Zero Advertising & No Data Commercialization

Religious practice and private spiritual struggle represent the most sensitive categories of personal human data. AMAL OS adheres to an inviolable charter:

- **No Targeted Advertising**: User worship patterns, prayer completion, missed prayers, and spiritual queries will **never** be monetized, shared with data brokers, or used for advertising.
- **No Moral Scoring**: The system never calculates an "Iman score" or assigns moral grades to human beings.
- **Purpose Limitation**: Data collected is utilized solely to personalize routines and journeys requested by the user.

## 2. Privacy Lifecycle: Minimal Data to Erasure

```text
MINIMUM DATA
      ↓
EXPLICIT CONSENT
      ↓
PURPOSE LIMITATION
      ↓
FIELD-LEVEL ENCRYPTION
      ↓
ACCESS CONTROL
      ↓
IMMUTABLE AUDIT LOG
      ↓
DATA PORTABILITY (GDPR JSON EXPORT)
      ↓
RIGHT TO BE FORGOTTEN (INSTANT ERASURE)
```

---

## 3. User Data Rights

1. **Transparency**: Users can view the exact items the AI remembers via the **Privacy Center** (`/api/v1/privacy`).
2. **Selective Memory Purge**: Users can delete individual memory items or clear all contextual memory at any moment.
3. **Data Export**: Full export of profile, journeys, reflections, and prayers in structured JSON format.
4. **Account Erasure**: Immediate, irreversible cascade deletion of all user records, sessions, and journal entries.
