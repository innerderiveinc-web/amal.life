## 3. Strict Preference Hierarchy Enforcement

In accordance with Section 4 and 9:
1. **Tier 1: Explicit User Choice** (Weight: 1.0, Inviolable)
2. **Tier 2: User-Confirmed Preference** (Weight: 0.9)
3. **Tier 3: Strong Repeated Behavioral Pattern** (Weight: 0.75, $\ge 5$ observations, consistency $> 75\%$)
4. **Tier 4: Weak Behavioral Pattern** (Weight: 0.5, $3-4$ observations)
5. **Tier 5: AI Inference** (Weight: 0.3, Pure model heuristic)

### Conflict Resolution Rule
When explicit preference conflicts with observed behavior (e.g. User explicitly selected Morning, but completes 7 of 8 actions in the Evening):
- **AMAL OS NEVER silently overwrites the explicit choice.**
- Generates a respectful prompt: *"We noticed recent actions seem to fit an Evening routine. Keep your current Morning preference or try Evening?"*
- The seeker retains complete sovereign autonomy.
