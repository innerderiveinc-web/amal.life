# AMAL OS — Production Documentation & Platform Directory

> **A trusted, privacy-first, scholar-governed, evidence-backed, adaptive Muslim life operating system that helps users move from Niyyah to sustainable Amal.**

AMAL OS V1.0 combines:
1. **V0.1 Deterministic Core Engine**: Auth, User Profile, Preferences, Goals, Baselines, Journeys, Today Schedule, Amal Completion, Reflections, Prayer Times, Privacy.
2. **V0.5 Governed Knowledge & Evidence Layer**: Verified Quranic text, canonical Hadith collections, Islamic concept taxonomy, Claim Ledger, Hybrid Retrieval, Zero-Fabrication Citation Auditor, Multi-Class AI Runtime (Classes A–E).
3. **V0.8 Scholar Network & Human Governance**: Human scholar escalation, Two-Jurist Dual Review rule (`INV_07`), Family workspace with strict domestic privacy and Adult Muhasabah reflection vault isolation (`INV_03`), Adaptive Amal friction relief, Responsible communication engine.
4. **V1.0 Production Platform & Hardening**: Canonical Entitlement Engine (Free, Plus, Family, Institution), Cryptographic Webhook Engine (HMAC-SHA256, Anti-Replay Idempotency), Multi-Tenancy Data Isolation, Resiliency Circuit Breakers (`StopTheLineController`), Observability, Disaster Recovery, Security Pen-Testing, Full Production Validation.
