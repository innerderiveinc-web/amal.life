# AMAL OS V1.5 — PRIVACY, ZERO-KNOWLEDGE & DOMESTIC VAULT REPORT

## 1. Overview
AMAL OS V1.5 guarantees that personalization does not degenerate into surveillance. The system enforces strict Zero-Knowledge boundaries across family members, administrators, and LLM inference engines.

## 2. Invariant INV_03 Verification (Domestic Isolation)
- **Adult Muhasabah Reflections Vault**: Adult reflection notes (`wentWell`, `couldImprove`, `tomorrowIntention`, `notes`) remain 100% private to the individual user.
- **Household Head Restrictions**: Household heads can inspect aggregated family challenges and joint Quran goals, but any attempt to query adult member reflection vaults returns `403 FORBIDDEN` with code `POLICY DENIAL (INV_03)`.
- **Zero Training Invariant**: User Muhasabah reflections are excluded from any AI fine-tuning or model training datasets.

## 3. Context Firewall V2
Before any personal memory or context signal is provided to an AI model:
1. **Purpose Verification**: Signal must be strictly necessary for the active user question.
2. **PII Sanitization**: Personal identifiers, private journal notes, and payment details are permanently redacted.
3. **Stateless Snapshot**: Context is supplied as an ephemeral snapshot; model cannot write back unconfirmed changes into persistent user profiles.

## 4. GDPR & Right-to-be-Forgotten Compliance
- **Complete Deletion**: Triggering `DELETE /api/v1/memory/:id` removes the record from active tables and cache.
- **Cascading Invalidation**: Deleting a confirmed memory automatically invalidates any downstream derived context signals and resets recommendation weights back to neutral baseline.
- **Data Portability**: Users can export their entire memory, reflection, and habit history in portable JSON format.
